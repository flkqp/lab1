### Ответы на контрольные вопросы

**1. Какие параметры можно указывать в SettingsConfigDict?**

SettingsConfigDict позволяет настраивать поведение Pydantic Settings.

Основные параметры:

- `env_file` - путь к файлу с переменными окружения.
- `env_file_encoding` - кодировка файла переменных окружения.
- `extra` - обработка дополнительных полей.
- `case_sensitive` - чувствительность имён переменных к регистру.
- `env_prefix` - префикс переменных окружения.
- `validate_default` - проверка значений по умолчанию.

В лабораторной работе используются `env_file`, `env_file_encoding` и `extra`.

**2. Для чего нужны параметры mapped_column?**

`mapped_column` используется для описания столбцов таблицы при создании SQLAlchemy ORM-моделей.

Основные параметры:

- `primary_key` - определяет первичный ключ.
- `nullable` - разрешает или запрещает NULL.
- `unique` - устанавливает уникальность значения.
- `index` - создаёт индекс.
- `autoincrement` - включает автоматическое увеличение значения.
- `default` - задаёт значение по умолчанию на стороне Python.
- `server_default` - задаёт значение по умолчанию на стороне базы данных.
- `comment` - добавляет описание столбца.

**3. Для чего нужен параметр echo в create_async_engine?**

Параметр `echo` отвечает за вывод SQL-запросов в журнал приложения.

- `echo=True` - SQL-запросы выводятся в лог, что удобно при отладке.
- `echo=False` - SQL-запросы не выводятся таким способом.

В лабораторной работе используется `echo=True` для контроля выполнения SQL-запросов.

### Ответы на контрольные вопросы

**1. Что произойдёт с access-токеном, если удалить refresh-токен из базы данных?**

При удалении refresh-токена связанный с ним access-токен также удаляется из базы данных благодаря внешнему ключу с параметром `ON DELETE CASCADE`.

Сам JWT access-токен остаётся действительной строкой на стороне клиента, но сервер больше не сможет подтвердить его действительность, поскольку соответствующая запись отсутствует в базе данных. Поэтому такой токен не пройдёт проверку авторизации.

**2. Для чего класс RegexEnum наследуется от str и Enum?**

Наследование от `str` и `Enum` позволяет создавать перечисления, элементы которых одновременно являются строковыми значениями и элементами перечисления.

Это обеспечивает совместимость с типами строк, валидацией Pydantic, регулярными выражениями и JSON-сериализацией.

**3. Для чего нужен отдельный TokensController?**

Отдельный `TokensController` предназначен для централизованного управления созданием и обновлением токенов.

Он позволяет вынести общую логику генерации access-токена и refresh-токена в отдельный компонент, чтобы не дублировать её в контроллерах аутентификации и авторизации.

Такое разделение упрощает поддержку приложения, повторное использование кода и соблюдение принципа единственной ответственности.
