### Ответы на контрольные вопросы

**1. Какие параметры можно указывать в SettingsConfigDict?**

SettingsConfigDict позволяет настраивать поведение Pydantic Settings.

Основные параметры:
- `env_file` - путь к файлу с переменными окружения.
- `env_file_encoding` - кодировка файла переменных окружения.
- `extra` - обработка дополнительных полей.
- `case_sensitive` - чувствительность имён переменных к регистру.
- `env_prefix` - префикс переменных окружения.
- `validate_default` - проверка значений по умолчанию.

В лабораторной работе используются `env_file`, `env_file_encoding` и `extra`.

**2. Для чего нужны параметры mapped_column?**

`mapped_column` используется для описания столбцов таблицы при создании SQLAlchemy ORM-моделей.

Основные параметры:
- `primary_key` - определяет первичный ключ.
- `nullable` - разрешает или запрещает NULL.
- `unique` - устанавливает уникальность значения.
- `index` - создаёт индекс.
- `autoincrement` - включает автоматическое увеличение значения.
- `default` - задаёт значение по умолчанию на стороне Python.
- `server_default` - задаёт значение по умолчанию на стороне базы данных.
- `comment` - добавляет описание столбца.

**3. Для чего нужен параметр echo в create_async_engine?**

Параметр `echo` отвечает за вывод SQL-запросов в журнал приложения.

- `echo=True` - SQL-запросы выводятся в лог, что удобно при отладке.
- `echo=False` - SQL-запросы не выводятся таким способом.

В лабораторной работе используется `echo=True` для контроля выполнения SQL-запросов.
